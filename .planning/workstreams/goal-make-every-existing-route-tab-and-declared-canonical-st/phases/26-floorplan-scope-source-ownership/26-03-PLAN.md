<interfaces>
`UiOpaqueOwnerId` and `UiOpaqueRegionId` are opaque literal types whose values use fixed non-semantic tokens (for example `uio-`/`uir-` plus a lowercase alphanumeric token) and must not contain a route, file, symbol, fragment, slash, backslash, extension, or absolute-path prefix. `UiSourceOwnershipKey` is deterministically built from `scopeKey + ownerId + regionId`.

`UiSourceOwnershipTarget` declares `scopeKey`, `ownerId`, `regionId`, and nullable `parentRegionId`. `uiSourceOwnershipTargets` is the canonical expected opaque identity set: every 26-01 scope key has exactly one parentless root target, and every additional region target resolves its parent inside the same scope and owner.

`UiSourceOwnershipManifestEntry` carries the same identity fields plus `sourceFile`, `sourceSymbol`, and `sourceFragment`. `sourceFile` is a normalized repository-relative path rooted at `frontend/src` but stored relative to the frontend root as `src/...`; `sourceSymbol` identifies exactly one named function, class, variable, or named default-export declaration in that file. `UiSourceFragmentLocator` is a discriminated AST locator supporting exact `jsx-tag`, `jsx-string-attribute`, `call`, or `identifier` selectors; a valid locator matches exactly one node inside the resolved symbol declaration.

`compareUiSourceOwnershipSets(targets, manifest, scopeKeys, resolutions)` returns sorted `missing`, `duplicates`, `orphans`, and `stale` key collections. `missing` means a target key has no manifest row; `duplicates` means a manifest key occurs more than once; `orphans` means a target/manifest row references an unknown scope key or a region parent absent from the same scope/owner; `stale` means a manifest key has no valid confined file, exactly-one symbol declaration, or exactly-one symbol-bounded fragment match. No count-only result is accepted.
</interfaces>

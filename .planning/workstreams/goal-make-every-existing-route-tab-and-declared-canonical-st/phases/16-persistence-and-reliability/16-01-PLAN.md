# Phase 16 Plan 01: Persistence and reliability

## Objective

Close Step 16 from the architecture audit in small atomic slices while preserving runtime behavior and all existing database data.

## Work packages

1. Map current EF configuration ownership and extract feature mappings incrementally.
2. Inventory transaction boundaries and introduce an execution-strategy-aware runner with characterization tests.
3. Inventory business `InvalidOperationException` paths, define mapped exceptions and convert them feature by feature.
4. Reconcile migration lineage with non-mutating fresh/upgrade tests and written evidence.
5. Produce off-site backup/restore guidance and rehearse only on a disposable clone.

## Verification

- Focused tests after every slice.
- Full backend and frontend suites, Release build, lint, dependency check, production build, OpenAPI/TypeScript determinism and EF pending-model gate.
- `git diff --check`, secret scan and staged GitNexus `detect_changes` before each commit.
- No browser run unless public frontend/route/UI behavior changes.

## Prohibited operations

- No push or reset.
- No seed/import into existing databases.
- No mutation of `ipc_lane1`.
- No rewrite, deletion or movement of applied migrations.

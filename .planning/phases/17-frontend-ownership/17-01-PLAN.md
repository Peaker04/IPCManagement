# Phase 17 Plan 01: Characterize the ownership-sensitive public contract

<objective>
Create a red/green safety net for the exact endpoint, hook, cache, layout, and projects/coordination boundaries before moving production modules.
</objective>

<threat_model>
- **T-17-01 HIGH — session/cache fragmentation:** a second API slice or changed endpoint key silently creates a second cache and bypasses the shared refresh pipeline. Mitigation: identity, reducerPath, endpoint-key, hook-export, and invalidation characterization.
- **T-17-02 MEDIUM — authorization/navigation regression:** ownership moves can bypass current permission filtering or route preload behavior. Mitigation: raw-source boundary assertions plus existing behavior tests.
</threat_model>

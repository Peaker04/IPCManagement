# Project Retrospective

*A living document updated after each milestone. Lessons feed forward into future planning.*

## Milestone: v1.3 — UI Completeness & Conformance

**Shipped:** 2026-08-02
**Phases:** 7 | **Plans:** 27 | **Sessions:** not reliably derivable from repository evidence

### What Was Built

- Test-owned lifecycle/action registries and FE/BE permission-vocabulary guards.
- A six-family read-only PC action oracle across five desktop viewports.
- Approved PB/PE component canon with exact source inventories and contextual exceptions.
- Permanent UI=f(state), hidden-state and conformance checks in root verification.

### What Worked

- Source-aware binary contracts prevented speculative UI and permission changes.
- Small canon slices with exact callsite inventories kept behavior stable.
- Current-source headed evidence and immutable DB constraints prevented false API-only claims.

### What Was Inefficient

- The roadmap expanded before it was mapped directly back to the addendum.
- Screenshot files were generated and hashed without being independently read.
- Historical quick-task directories lacked terminal summaries and blocked milestone archival.

### Patterns Established

- GSD owns process state; GitNexus rigor is selected by semantic lane.
- Unknown contract cells remain unknown rather than being filled from convention.
- Visual evidence must connect declared state, rendered control, request and source owner.

### Key Lessons

1. A green overflow counter is not proof that row actions or table bottoms are visually intact.
2. A screenshot is not machine evidence until a separate judge actually receives and inspects it.
3. Floorplan intent must be declared before visual conformance can be evaluated.
4. Historical artifact status needs an explicit terminal summary even when later work supersedes it.

### Cost Observations

- Model mix: not recorded in repository evidence.
- Sessions: not recorded reliably enough to report.
- Notable: repeated broad audits were expensive because route/tab coverage and image judgment
  were not represented by one source-linked manifest.

# Documentation archive

Các file dưới `docs/archive/` là audit, research, checklist hoặc closeout theo thời điểm đã bị nguồn canonical
mới hơn thay thế. Chúng được giữ để truy vết quyết định, **không có execution authority** và không được auto-load.

Khi nội dung archive mâu thuẫn với code/runtime, `MEMORY.md`, phase đang mở hoặc contract canonical được liệt kê
tại [`../README.md`](../README.md), luôn ưu tiên các nguồn hiện hành đó.

Không thêm task mới vào file archive. Finding còn sống phải được fact-check rồi chuyển vào finding ledger/phase
hiện hành do GSD sở hữu.

# Lean CI/CD Implementation Plan

> Execute natively with superpowers:executing-plans. User approved all audit verdicts; no further plan approval is needed. WORK is the sole progress ledger. No commits, worktrees, subagents, installs, source DB writes, hosted dispatch or deployment.

**Goal:** Shorten feedback paths and close CI evidence gaps without removing gates.

**Spec:** `.artifacts/ci-cd-audit/REVIEW.md`, eight approved findings. OPERATIONS remains release authority.

**Architecture:** Keep Verify and CodeQL. Verify has independent frontend/backend jobs and the existing stable verify check as a fail-closed aggregate. Small scripts own test evidence and schema comparison; npm owns common fast gates.

**Owners:** `.github/workflows/{verify,codeql}.yml`, `package.json`, `scripts/ci-*`, fixture determinism script, existing repository-entrypoint guard, OPERATIONS. Runtime compatibility is a separately assessed task; do not change migration history or adopt an unproven MySQL provider.

## Global constraints

- Preserve all current hard gates and existing advisory status; no path-skipped required workflow.
- Keep MySQL integration/fresh/upgrade/schema steps sequential in one backend job.
- Preserve Release OpenAPI generation and two independent fixture outputs.
- Never count zero/missing/skipped/duplicate required migration cases as success.
- Keep seven-day diagnostic retention; upload only selected reports, no dumps/secrets/workbooks.
- Inherited main working tree stays in place. No extra state ledger or independent reviewer against user restrictions.
